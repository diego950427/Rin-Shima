# UT-checker

北市大學分規劃工具的新外觀預覽。左側使用提供的搖曳露營 GIF，右側以留白與分區文字呈現。

目前只有前端外觀、選單、頁面導覽與動畫暫停功能；尚未接上成績匯入、畢業審核或任何後端。不收集個人成績，也不取代原版畢業通。

## 本機預覽

在專案目錄執行 `python -m http.server 8520 --bind 127.0.0.1`，再開啟 http://localhost:8520 。也可直接開啟 `index.html`。
